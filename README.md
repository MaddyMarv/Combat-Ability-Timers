### [Ability Timer](https://www.nexusmods.com/warhammer40kdarktide/mods/673)

HUD countdown timer showing the active duration of your combat ability.

**Display**
- Show Ability Timer UI
- Display mode [Timer and Progress Bar, Progress Bar Only, Timer Only]
- Always Show Bar
- Show ability charges
- Always show charges (even at 1 or 0)
- Show bracket
- Show decimals
- Timer Target [Current / Next Charge Only, Until Full (All Charges & Duration)]
- Show Bubble Shield Health
- Bubble Health Display Mode [Both (Mirror Ability Bar), Both (1st Placed | 2nd Placed), Lowest Health Only, Newest Bubble Only, Oldest Bubble Only]
- Use Scrier's Gaze tracking bar

**Gauge**
- Gauge length
- Gauge thickness
- Opacity
- Orientation [Horizontal, Vertical]
- Bar direction [Start, End, Center]
- Segment Multi-Charge Bar
- Bar Display Target [Until Full (All Charges & Duration), Current / Next Charge Only]
- Independent Charge Tracking
- Fixed Charge Slots
- Consume Order [Right to Left, Left to Right]
- Segment Gap
- Bar Notches [None (Solid), 2 Notches, 3 Notches, 4 Notches, 6 Notches]
- Notch Length (%)
- Notch Width
- Track cooldown
- Cooldown display mode [Smooth (start from remaining), Full (show complete cooldown)]

**Colors**
- Static Bar Color / Static Text Color (Without Progress Color)
- Use progress color (Bar / Text)
- High / Mid / Low Duration Color (Progress)
- Ready Charge Color
- Notch Color
- Static Cooldown Color
- Use progress color for cooldown
- Cooldown Start Color (0%) / Cooldown Finish Color (100%)
- Static Peril Color
- Use progress color (Scrier's Gaze / Peril)
- Peril Low Color (0%) / Peril High Color (100%)

**Positions**
- X/Y offset (Bar, Timer, Charges, Bubble Health)
- Text size (Timer, Charges, Bubble Health)
- Text alignment [Left, Center, Right] (Timer, Charges, Bubble Health)

**Ability filters**
